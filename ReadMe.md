# AI Expense Tracker

An AI-powered personal expense tracking application built with Spring Boot, React, PostgreSQL, and Ollama.

## 🚀 Features

- User registration and login
- JWT-based authentication
- Expense management
- Income management
- Category management
- Monthly budgets
- Budget alert notifications
- Expense reminders
- AI-powered financial insights
- AI chat assistant
- Monthly and daily expense analysis
- Notification management
- User profile management
- Change password
- Forgot password with OTP verification
- PostgreSQL database

## 🛠️ Tech Stack

### Backend

- Java 25
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- JWT
- Lombok
- Jakarta Validation
- Spring Mail
- Maven

### Frontend

- React
- Vite
- React Router
- Material UI
- Axios
- Recharts
- Day.js

### AI

- Ollama
- AI-powered financial insights
- AI chat assistant
